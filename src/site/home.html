Guchho

Fast, HTML-first bundler for the web

An all-in-one bundler, compiler and build tool. Parse HTML, JavaScript, TypeScript, JSX, CSS and assets, and produce a deployable output directory with a single command.

Everything in one tool

Native bundler

A single native executable that bundles your app, JS, TypeScript, CSS and assets with extreme speed and incremental rebuilds that stay fast as the project grows.

Core concepts

HTML-first

Point Guchho at your HTML entrypoints. It follows scripts, styles, images and imports and rewrites them into a production-ready output directory.

HTML pipeline

Dev server & watch

Rebuilds almost instantly when files change, with a built-in dev server, live reload, and hot rebuilds for rapid iteration.

Dev server

Tree shaking

Dead code is eliminated from your bundles so the code that ships is the code that runs.

Tree shaking

Minification

Whitespace, identifiers and syntax minification produce smaller output without changing the result.

Minification

Plugin API

Extend every stage of the pipeline with a clean plugin API, or embed Guchho in your own tools.

Plugins
