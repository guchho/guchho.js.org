Native bundler

A single native executable that bundles your app, JS, TypeScript, CSS and assets with extreme speed and incremental rebuilds that stay fast as the project grows.

Core concepts

HTML-first

Point Guchho at your HTML entrypoints. It follows scripts, styles, images and imports and rewrites them into a production-ready output directory.

HTML pipeline

Dev server & watch

Rebuilds almost instantly when files change, with a built-in dev server, live reload, and hot rebuilds for rapid iteration.

Dev server

Tree shaking

Dead code is eliminated from your bundles so the code that ships is the code that runs.

Tree shaking

Minification

Whitespace, identifiers and syntax minification produce smaller output without changing the result.

Minification

Plugin API

Extend every stage of the pipeline with a clean plugin API, or embed Guchho in your own tools.

A minute with Guchho

One tool for the whole workflow.

Scaffold, develop, build, preview and ship with the same binary. Every step below is a real command with real output — click one, or just watch.

  1. Creates an HTML entrypoint, a script, a stylesheet and a config file — nothing to clean up later. Docs
  2. Instant rebuilds and live reload at a local URL the moment you save a file. Docs
  3. Bundles HTML, JS, CSS and assets into a minified, fingerprinted output directory. Docs
  4. Serve the built output locally to check exactly what you are about to deploy. Docs
  5. Zip the output directory into a release artifact, ready to upload anywhere. Docs
