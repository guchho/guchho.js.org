Examples

Ready-to-run projects in a variety of setups. Each example lives in the examples folder of the repository.

Single-file apps

  • Vanilla JavaScript — an HTML entrypoint that imports a module, a stylesheet and an SVG asset.
  • TypeScript + JSX — typed input with strict checking and automatic JSX transform.

Frameworks

  • React — a component app bundled to a couple of files with tree shaking enabled.

Libraries

  • Library build — compiling a small package to an IIFE with a global namespace for use from a plain <script> tag.

Run them locally

git clone https://github.com/guchho/guchho
cd guchho/examples/vanilla
npm install
npm run build   # or npm run dev for the dev server
